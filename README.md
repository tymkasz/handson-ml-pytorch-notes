# Hands-On ML with Scikit-Learn and PyTorch – my learning journey

This repository documents my machine learning studies based on the book
*Hands-On Machine Learning with Scikit-Learn and PyTorch* by Aurélien Géron.

I rewrite the code from the original Jupyter notebooks ([ageron/handson-mlp](https://github.com/ageron/handson-mlp))
as plain Python scripts and add my own notes, exercise solutions and experiments.

## Getting started

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python ch02_end_to_end_project/main.py
```
